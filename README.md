# pairwise-tessellation-cracks

角色走到地形块边缘时，脚下的三角形裂开一条缝，相邻块细分因子不同，边界一侧 8 段另一侧 4 段；边缘顶点各自生成，位置只差浮点误差却拉开一个像素；细分因子按屏幕空间边长算，相机拉远后裂缝反而变大；位移贴图在边缘采样越界，钳到边界值后高度对不上；位移后的法线没有重算，裂缝处光照突变；补丁背面剔除开着，从下方看地形是空的；细分等级在距离阈值处直接跳变，走过去时地面弹一下；补丁边界 uv 没有对齐到同一纹素，位移高度差半个采样；阴影通道用了另一套细分因子，阴影边缘出现锯齿缝；高度图远处用了高 mip，位移幅度被抹平，接缝更明显。render/tessellation_cracks.py 是核心，tests/test_tessellation_cracks.py 15个红。要修的是：边因子取两侧最大；共享边顶点；按世界长度；边缘高度钳制；位移后重算法线；双面渲染；因子渐变；边界 uv 对齐；阴影同因子；高度图 mip 一致。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
